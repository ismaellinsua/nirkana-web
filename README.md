# nirkana.es

Web pública de NirKanA, publicada con GitHub Pages (rama `main`, carpeta `/docs`, dominio en `docs/CNAME`).

- `docs/`: la web (lo único que se publica) y la demo en `docs/demo/`.
- `notas/`: cómo se mantiene la web ([`notas/WEB.md`](notas/WEB.md)); no se publica.
- `ops/`: comprobación diaria del sitio, generador de textos legales y capturas.
- `tests/`: pruebas de que la web solo promete lo que la app hace y de que sus herramientas funcionan.
- `legal/`: plantillas de los textos legales (los datos reales del titular nunca se suben: `legal/datos.json` está en `.gitignore`).

El código de la aplicación NirKanA es privado y no está en este repositorio.
